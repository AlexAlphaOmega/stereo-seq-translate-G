## 5. 全新产品描述段（§1.1，P11）

**V1 标准范文**（可作为所有 Stereo-seq 产品描述的模板）：

> Go Spatial-V2-24, STOmics automated sample preparation system developed by MGI, automates batch processing of Fresh Frozen (FF) samples for Stereo-seq experiments. The system is now compatible with STOmics Stereo-seq Transcriptomics Set V1.3 for Go Spatial, which is intended for generating a spatially-resolved 3′ mRNA library from biological tissue sections. Built upon DNA Nanoball (DNB) technology, STOmics Stereo-seq Transcriptomics Set V1.3 for Go Spatial enables a "tissue-to-data" solution through in situ capture of the whole transcriptome at nanoscale resolution and centimeter-sized Field of View (FOV). This kit uses DNB-patterned array chips loaded with spatially-barcoded probes that capture and prime poly-adenylated mRNA from tissue sections in situ. Each cDNA synthesized from mRNA captured on a particular spot is linked to its spatially-barcoded probe, allowing subsequent gene expression mapping of a tissue section following sequencing and visualization analysis using the StereoMap visualization platform.
